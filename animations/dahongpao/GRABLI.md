# Грабли (симптом → причина и лечение)

| Симптом | Причина и лечение |
|---|---|
| Руки персонажа как «трубы зомби» | рукава толстые и длинные. Рукав: 0.028/0.03/0.042·H, плечо 0.14·H, предплечье 0.125·H |
| В поклоне руки вытянуты вперёд | руки считаются от корпуса: при наклоне 40° нужно sh≈5°, el≈80°, чтобы кисти были у груди |
| Персонажи мелкие, низ кадра пустой | общий план крупнее: камера `BASE` s=1.15, земля у нижней кромки (над зоной интерфейса 15%) |
| Подпись не читается поверх скалы | под подписью стираем фон (`eraseRect`) — «подложка» под текст |
| Мантия в руках еле видна | полотнище должно быть крупным: ~190×230 px, иначе в общем плане теряется |
| Фигура прозрачная, видно скалу сквозь халат | перед заливкой каждой части `erase()` её силуэта — фигура непрозрачна |
| **Персонажи с анимацией ходьбы выглядят стрёмно** | код-кукла не тянет красивых людей. Формат «книжка»: статичные карточки, люди только силуэтом вдали, историю рассказывают предметы |
| Под переворачиваемой страницей пустой лист | следующая карточка начинает прорисовку только через 0.5 с после начала перехода — это нормально, читается как «чистая страница» |
