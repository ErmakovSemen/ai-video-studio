# Да Хун Пао — легенда о красной мантии (карандашный мульт кодом)

Метод: методичка «Мультики кодом» — HTML+canvas, рендер HyperFrames, звук синтезом. Без генераций.

- `STORYBOARD.md` — сценарий и раскадровка
- `timing.json` ← `build_timing.py` — константы времени: окна ходьбы (по ним же шаги в звуке), поворот, бросок мантии, паузы на чтение
- `engine.js` — карандашный движок (общий с jinjunmei)
- `figure.js` — **персонаж-кукла**: скелет с суставами → халат, рукава, голова, шапка; позы `POSES`, смешивание `mix`, цикл ходьбы `walk`
- `scenes.js` — сцены; `index.html` — композиция (`window.THEME` = `kraft` | `ink`)
- `audio.py` — звук; `render.sh` — сборка; `sheet.sh` — лист кадров
- `out/dahongpao_kraft.mp4` — готовый ролик (40.8 с), `out/sheet.png` — лист кадров

Сборка: `./render.sh kraft high` (~3 мин).
