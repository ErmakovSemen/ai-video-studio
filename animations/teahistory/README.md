# История чая — коллаж-гравюра (ransom-заголовки + гравюры кодом + вклейки)

Формат: 9:16, 65 с, 7 глав (Шэнь-нун → Тан → Сун → Мин → 1638 → самовар → сегодня).
Каждая глава — серый лист с газетными обрывками и следами от чашки; новый лист въезжает справа с рваным краем.
Камера медленно наезжает (3% за главу). В кадре почти ничего не движется: элементы появляются по одному разу.

Порядок появления в главе: метка-полоска → заголовок из вырезанных букв → гравюра-вырезка (белая высечка) →
вклейки (документ на скотче, марка, билет) → пометка от руки со стрелкой → текст на машинке → печать.

- `engrave.js` — **гравюра кодом**: тон = толщина и густота резцовых линий. Тела вращения (`revolve`: широтные дуги +
  меридианы в тени), плоские детали (`part`: параллельная штриховка, перекрёстная в тенях). Предметы: котёл, свиток с книгой,
  чаша с венчиком, чайник, компас, самовар, чашка. 3 варианта на предмет — «кипение» линий.
- `collage.js` — элементы коллажа: `ransom` (буквы разных шрифтов на обрывках), `label`, `tape`, `cutout`, `doc` (рваный край,
  скотч), `typed` (машинка с кареткой), `postage`, `ticket`, `seal`, `scribble`, `newsprint`, `stain`, `clip`
- `scenes.js` — раскладка 7 глав; вклейки «Ча цзин», указ 1391 года, карта Чайного пути (Пекин → Кяхта → Москва)
- `build_timing.py` → `timing.json/js` — тексты и время каждого элемента; звук берёт оттуда же события
- `audio.py` — свой звук на каждый элемент (буква, клавиша, каретка, скотч, марка, печать, лист), фон глав (огонь, кипение, налив),
  музыка: пентатоника → «балалайка» в ре миноре → соль мажор и финальный аккорд
- `render.sh` — сборка (~5 мин), `sheet.sh` — лист кадров; шрифты — `fonts/` (Google Fonts, OFL)
- `out/teahistory.mp4`, `out/sheet.png`

## Откуда идеи
- референс пользователя: коллаж «EVERY BOOK» — буквы-вырезки, гравированный монах-наклейка, рукопись на скотче, метка «1. BEFORE THE PRESS»
- методичка «Мультики кодом»: последние 3 с — постер, первый кадр не пустой, нижние 15% свободны, звук −16…−14 LUFS
