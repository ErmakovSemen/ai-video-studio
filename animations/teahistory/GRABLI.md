# Грабли (симптом → причина и лечение)

| Симптом | Причина и лечение |
|---|---|
| Буквы заголовка и документы съехали/наложились | раскладка считалась до загрузки шрифтов. После `document.fonts.load` — `COLLAGE.reset()` и перерисовка |
| CDN jsdelivr недоступен в рендере | `gsap.min.js` лежит локально |
| Тела вращения с плоским белым верхом, «угловатые» | у `revolve` по умолчанию эллипс-крышка; профиль сглаживается `smooth(profile, 6)` |
| Огонь под котлом не читается | языки пламени — «стручки» с тёмной штриховкой + поленья + искры |
| Компас — каша из линий | половинки лучей: одна сплошная чёрная, другая белая |
| Ручки самовара — тёмные блоки, кран «на» корпусе | ручки = тонкие кронштейны + деревянные «бочонки» с вертикальной штриховкой; кран вынесен за силуэт |
| Печать легла на текст машинки | печать ставится после текста в свободный угол (координаты проверять по листу кадров) |
| Первый кадр пустой (только бумага) | у главы 1 `local0 = -0.8` — заголовок уже на кадре 0; события с t < 0 звук отбрасывает |
| Полный черновой рендер ради проверки — 2+ мин | быстрые стоп-кадры: Playwright открывает `index.html` через локальный http, вызывает `SCENES.render(t)` и снимает canvas |
