# Грабли (симптом → причина и лечение)

| Симптом | Причина и лечение |
|---|---|
| Буквы заголовка и документы съехали/наложились | раскладка считалась до загрузки шрифтов. После `document.fonts.load` — `COLLAGE.reset()` и перерисовка |
| CDN jsdelivr недоступен в рендере | `gsap.min.js` лежит локально |
| Тела вращения с плоским белым верхом, «угловатые» | у `revolve` по умолчанию эллипс-крышка; профиль сглаживается `smooth(profile, 6)` |
| Огонь под котлом не читается | языки пламени — «стручки» с тёмной штриховкой + поленья + искры |
| Компас — каша из линий | половинки лучей: одна сплошная чёрная, другая белая |
| Ручки самовара — тёмные блоки, кран «на» корпусе | ручки = тонкие кронштейны + деревянные «бочонки» с вертикальной штриховкой; кран вынесен за силуэт |
| Печать легла на текст машинки | печать ставится после текста в свободный угол (координаты проверять по листу кадров) |
| Первый кадр пустой (только бумага) | первые 1,6 с — обложка, она видна целиком с кадра 0 (`renderCover`); раньше главе 1 ставили `local0 = -0.8` |
| В заголовке обложки буква читается плохо (вычурный шрифт) | шрифт и бумага буквы зависят от `id` в `C.ransom`: перебрать `id`, сравнить стоп-кадры и оставить читаемый вариант |
| Полный черновой рендер ради проверки — 2+ мин | `node stills.cjs . out/stills.png 0 6 …`: Playwright открывает `index.html` через локальный http, вызывает `SCENES.render(t)` и снимает canvas |
| `require is not defined` в утилите на Node | в `package.json` стоит `"type": "module"`, поэтому CommonJS-скрипт должен быть `.cjs` |
| Озвучка ElevenLabs через Higgsfield звучит «ужасно» (оценка владельца) | все пресеты Higgsfield — англоязычные голоса (проверено Whisper по превью); по-русски они говорят с акцентом. Для русской озвучки нужен родной русский голос: свой голос, Yandex SpeechKit или клон с русской записи |
| Файлы с CDN Higgsfield не скачиваются в контейнер | сеть среды закрыта; сведение делается в песочнице Higgsfield (`sandbox_exec`): она берёт ролик из GitHub по raw-ссылке и выкладывает результат через `media_upload` |
