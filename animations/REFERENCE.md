# Эталон: «История чая» (`teahistory/`)

**Статус:** эталонный кейс для роликов «мульты кодом», утверждён владельцем 14.10.2026.
Новый ролик начинаем **с копии `teahistory/`**, а не с нуля. Видео: `teahistory/out/teahistory.mp4`, лист кадров: `teahistory/out/sheet.png`.

Генерация идёт кодом в сессии: HTML + canvas → рендер HyperFrames, звук синтезируется в Python. Сайт и платные генерации не используются.

## Почему это работает
- **Кадр детальный и статичный.** Движение есть только в трёх местах: элемент один раз появляется, линии «кипят» (12 рисунков/с), лист сменяется.
- **Плотность.** В каждой главе 4–6 вставок разных типов: документ на скотче, марка, билет, пометка от руки, печать, газетные обрывки.
- **Длина.** 65 с: 7 глав по 8–10 с.
- **Гравюра кодом** (`engrave.js`) бесплатна и даёт стабильное качество. Тон передаётся толщиной и густотой линий.
- **Типографика коллажа:** заголовок из вырезанных букв (13 шрифтов), метка главы, текст на машинке.
- **Звук на каждый элемент** и фон по главам. Звук и картинка берут время из одного таймлайна.

## Формула главы (локальное время, с)
| t | Элемент | Звук |
|---|---|---|
| 0.0 | метка главы въезжает | шорох |
| 0.25 | заголовок по букве, шаг 0.06 | бумажный шлепок |
| 1.1 | гравюра-вырезка с белой каймой | глухой стук |
| 1.9 | вклейка 1: документ на скотче, марка или билет | скотч |
| 2.4 | вклейка 2 + пометка от руки со стрелкой | шлепок |
| 2.9 | текст на машинке, 24 знака/с | клавиши, каретка |
| конец текста + 0.3 | красная печать | удар |
| дальше | ≥ 2 с на чтение | — |

Смена главы: новый лист 0.6 с въезжает справа с рваным краем. Камера наезжает на 3% за главу.

## Раскладка кадра 1080×1920
- Метка главы: (60, 110). Заголовок: центр (545, 330), 150 px (128 px, если в заголовке больше 9 знаков), ширина ≤ 940.
- Гравюра: размер 760, центр около (520, 900–960).
- Вклейки стоят по углам вокруг гравюры. Её край перекрывать можно, заголовок и текст — нельзя.
- Текст машинкой: x 110, y 1330–1420, 52 px, ≤ 4 строк по ≤ 28 знаков.
- Нижние 15% (y > 1632) пустые. Печать ставится в свободный угол после текста.
- Фон: серый лист своего тона, 2 газетных обрывка, след от чашки.

## Правила контента
- Одна глава — один факт, один предмет и одна дата. Факты должны быть проверяемыми.
- Первый кадр не пустой: у первой главы `local0 = -0.8`, поэтому заголовок виден уже на кадре 0.
- Последние 3 с — постер: всё стоит, финальный аккорд.

## Новый ролик за 6 шагов
1. `cp -r animations/teahistory animations/<id> && rm -rf animations/<id>/out`
2. `build_timing.py`: в `SCENES` задать тексты, предметы, печати и длительности глав.
3. `engrave.js`: добавить предметы в `OBJ`. Тела вращения — через `revolve` (профиль `[[y, r], …]`), плоские детали — через `part`.
4. `scenes.js`: в `SC[i]` разложить вставки главы, в `drawX` — содержимое документов.
5. `audio.py`: фон глав и музыка. Звуки элементов подтянутся из таймлайна сами.
6. Проверка:
   - `node stills.cjs . out/stills.png 0 6 28 …` — стоп-кадры за секунды, без рендера;
   - `./render.sh high` — полный рендер, ~5 мин;
   - `./sheet.sh out/<id>.mp4 out/sheet.png "…"` — лист кадров.

## Чек-лист перед отправкой
- [ ] Первый кадр с заголовком.
- [ ] Печати и вклейки не лезут на текст и заголовок, нижние 15% пустые.
- [ ] В каждой главе ≥ 4 вставок.
- [ ] После текста ≥ 2 с на чтение, финал держится 3 с.
- [ ] Громкость −16…−14 LUFS, пик ≤ −1 dBFS.
- [ ] Лист кадров просмотрен глазами. Грабли записаны в `GRABLI.md`.

## Чего не делать (из отзывов владельца)
- Анимировать ходьбу и персонажей: «люди некрасивые, анимации непонятные».
- Делать короткие ролики на 20–35 с с 1–2 вставками на кадр и слабой детализацией.
- Озвучивать русским TTS (RHVoice): голоса не понравились. Сейчас ролики без голоса.
- Тратить кредиты платных генераций (Higgsfield и др.) без явного «да».
