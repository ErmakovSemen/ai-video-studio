# Карп у Врат Дракона — видео-дневник (карандаш + акварель + скрапбук)

Формат: 9:16, 36 с, 6 страниц дневника на кремовой бумаге в точку, пружина слева, закладки-язычки.
Принцип: **минимум движения в кадре**. Кадр детально прорисован, «живёт» только кипением линий (12 рисунков/с).
Элементы появляются по одному разу своей анимацией, страницы сменяются листанием с уголка.

- `journal.js` — элементы дневника: `sticker` (высечка, тень, шлёп с отскоком), `tape` (washi раскатывается),
  `polaroid` (фото падает на страницу, подпись от руки), `sticky` (заметка с загнутым уголком), `stamp` (печать),
  `marker` (выделение), `arrow` (стрелка от руки), `tab` (закладка), `doodleStars`; бумага `makePage`, пружина `rings`
- `scenes.js` — страницы и рисунки (карп, река, водопад Лунмэнь, прыжок, дракон в облаках); листание `curl`
- `build_timing.py` → `timing.json` — **таймлайн по id элемента**: картинка берёт время появления, звук — вид элемента
- `audio.py` — у каждого вида элемента свой звук (скотч, шлепок, стук полароида, печать, маркер, карандаш, листание), вода, музыка
- `render.sh` — сборка (~3.5 мин), `sheet.sh` — лист кадров
- `out/carp_kraft.mp4`, `out/sheet.png`

## Откуда идеи
- story-to-handdrawn-video (агент-скилл «дневник-комикс»): камера стоит/медленно наезжает, переходы — склейка, затухание или листание с нижнего правого угла; страница ≤ 8 с, 1–3 строки подписи
- Digital Sketchbook на Opus 5.5 (Nelson Lee): фото, вклеенное как полароид на скотч, рядом рисунок
- Aimer Maganda Flipbook: наклейки нарисованы кодом (SVG), washi, рваная бумага, сгиб с тенью по линии
