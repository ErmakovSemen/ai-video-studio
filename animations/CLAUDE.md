# Мульты кодом

- Видео делаются кодом в сессии: HTML + canvas → рендер HyperFrames, звук синтезируется в Python. Сайт и платные генерации не используются.
- Эталон — `teahistory/`. Перед новым роликом прочитай `REFERENCE.md` и начни с копии `teahistory/`.
- Кадры проверяй через `node stills.cjs` и лист кадров до того, как показывать результат.
- Публикация — через GitHub Actions workflow «Publish video», порядок в `PUBLISH.md`. Метаданные ролика — в `<проект>/youtube.json`. Первая заливка нового ролика — unlisted.
